# Public POTASMS model research

This is a clean public-source repository, not the private iOS workspace history.
Never commit private SMS, personal weights, secrets, machine-specific paths or
full session transcripts. Raw public datasets download from pinned upstream
sources; retain licenses and attribution. Authored fixtures are explicitly
synthetic and correlated. Freeze membership, versions, seeds and SHA256 files.
Never choose checkpoints or thresholds on evaluation sets. Keep corrections
explicit. Do not equate foreground phone memory with SMS-extension acceptance.
Recipes must work with a user-selected work directory on a clean machine.
Do not overwrite a prior run. Report per-language false positives and recall.
